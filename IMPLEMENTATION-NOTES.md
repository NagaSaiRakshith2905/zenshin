## Phase 16 — Local hardening and release checks — 2026-10-31

Started release hardening locally; this phase is **in progress**, not accepted for launch. Global shortcuts now respect editable/dialog/composing/default-prevented input. Task title/description editors use native buttons, retain heading semantics, support Space and restore focus on keyboard save/cancel without committing IME Enter. Filters have unique labels/controls, receive focus and restore it on Escape/apply/cancel. Search has a visible touch close control, status announcements, bounded active-option state, stale-query/IME Enter protection and Back/query text synchronization. Search/filter forms no longer nest. Added focus/touch/long-title styles and deferred task activity fetching until the activity dialog opens.

Task-page hydration now batches projects, section/status context, selected tasks/children/prerequisites/parents and relations across the authorized page instead of loading whole project graphs once per project. It reuses the existing pure graph rules and repeatable-read transaction. Metadata/activity lists no longer load unused task graphs. Explicit project scope is pushed into the permitted-project CTE. Search ranks lightweight hits, materializes a bounded page and only then loads note/property text for snippet generation (full-text matching still happens in the hit queries); count/cursor queries do not render headlines. No schema migration or caching service was added.

Added four disposable-PostgreSQL read regressions for page/detail metadata parity, query budgets, metadata reads, ownership/grants, search cursors and snippets. Added a pure graph projection regression. `pnpm perf:check` uses the existing guarded local test-database harness, loads the agreed 50/10,000/50,000 fixture, asserts a 50-project page with a fixed read budget, records 20-sample warm p95 and actual EXPLAIN ANALYZE/BUFFERS plans, and fails at >=500 ms. A manually requested CI performance run prints its synthetic report/plans.
